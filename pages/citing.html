The Gadfly Citation Guide - 1st (and only) Edition

Citing like a Gadfly, so you never suffer Chicago again

The Gadfly has its own simple citation guide so that we can cite things without hassle. If there is no attribution for a point but you would still like it explained, notes are permitted. Use sparingly. This is the general formula:

Last name, First name. Link (if website), page number (if applicable). Date Published. “Title”/Caption.

Last Name, First Name.

  • Use name of the human author. If there is no human author, use the name of the organisation (e.g. Penguin Books, World Health Organisation, Toronto Sun, etc.) in italics
  • If there are multiple authors, list the last name of every author. Do not list the first name.

Link.

  • Only applicable if there is a website.
  • The link must be from the Internet Archive. If no such link exists, archive yourself first.

Page Number.

  • Include when using direct quotations, direct allusions to a specific quote, and paraphrasing specific passages (eg. “Page 18” for the 18th page)
  • For videos, replace with timestamp. (eg. 2:28)
  • For ebooks, use paragraph numbers starting from the section title. (eg. Chapter III, Paragraph 12)
  • Not mandatory for websites with no numbers. Paragraph numbers starting from section title may be used.

Date Published.

  • Recommended, but only required for sources that have no link.
  • Day, Month, Year format. If there is no day or month, disregard. The year is mandatory.
  • If no date is listed, write “date unknown”.
  • Use the ‘last modified’ (or that specific edition for a book’s) date when possible.

Caption/Title.

  • Italicise.
  • Use title when title is given.
  • Captions should be used when no title is available. Captions should be short descriptions of the media. 1 short sentence max. Be concise.
