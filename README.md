This is the website for my satirical school newspaper: The Gadfly.   

A simple static website with vanilla JavaScript, mostly coded by me, with AI assistance in places (Kagi Code, Claude 4.5 Sonnet, & Gemini Flash Lite). Of course, the content itself is certified No-AI; that means the issues and website contents are human-written.  

This website, and my maintenance/development, are the opposite of best practices, and I know it. I could do this much better, but I'm too lazy. I didn't know how to do it properly when I started, and now I have too much technical debt. You can use this website for visual inspiration if you want (why, though?), but it's really not good enough code or setup wise for a rational person to base anything on.  

Resources used:
* Hosting - GitHub Pages
* Domain purchase - Namecheap
* Font(s) - Mozilla Fira Mono (Regular, Medium, Bold)
* Email subscription - Buttondown (free tier)
