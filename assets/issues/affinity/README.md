# The Gadfly's issue 10 affinity file
Hi, this is the Affinity V3 file for the final issue of _The Gadfly_. It is the definitive version of _The Gadfly_'s layout, as designed by me—Mateo.

There are two parts to the Affinity file: the template itself (master pages), which is mostly layout. You can use this section however you want, as long as you attribute us; this would be a CC BY 4.0 (Attribution) licence.

The content itself—which, given the fact we use almost no outside assets, is all ours—is still "All Rights Reserved," though we'll be lax with it, of course. Just don't go stealing any of our articles and claiming it's yours!

I've kept both halves (content and template) attached because I think it's, first of all, neat to see how a completed issue looks in Affinity, but also a reference implementation; I make some design choices on the fly that are internally consistent within myself.

Anyway, feel free to do most/anything with this Affinity file. Please, though, don't make imposter versions of The Gadfly. I can't stop you, but it'd be nice if you _didn't_. If you use my template, ideally brand it as your own, yeah?
